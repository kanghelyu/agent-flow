# Third-Party Open-Source Components

## Desktop Pet

The desktop pet shell in `studio-pet/` is adapted from:

**pixelpets** — MIT License
https://github.com/JOhnsonKC201/pixelpets

A pixel cat (default black-and-white Tuxedo coat), stripped of the dog, settings window, mail/calendar/pomodoro, music, custom-coat editor, and notification bridge. It now polls AgentFlow Studio for status; touching the pet plays only the original touch animation, all commands live in the right-click menu, and it provides a continuous `0.2x–3.0x` size slider and low-power mode, with macOS/Windows/Linux launchers.

See `studio-pet/ATTRIBUTION.md` for details.
